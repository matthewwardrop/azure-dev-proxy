URLs without a scheme use HTTPS. HTTP destinations are always anonymous. HTTPS authentication follows the host mappings below.

Host mappings and temporary overrides

Edit mappings on localhost. Forwarded pages use a separate, read-only loopback origin.

Overrides take priority over persisted rules. Within overrides: exact hosts first, then the longest wildcard suffix. The first matching rule wins.

Temporary means temporary. Overrides disappear when this process exits, including automatic idle shutdown. Active requests and streams prevent idle shutdown; an open page does not.

Persisted configuration

Saving a temporary rule replaces its persisted mapping and removes the temporary override. Persisted changes update the configuration file and apply immediately.
